# Procesamiento del Lenguaje Natural — UNIR

## Descripción
Material de estudio y guías de preparación para la evaluación final de la materia **Procesamiento del Lenguaje Natural** de la Universidad Internacional de La Rioja (UNIR).

Cada guía de estudio incluye: conceptos clave, tablas comparativas, resumen rápido para repaso y claves del test de autoevaluación. Estas guías están diseñadas para ser usadas como **material de apoyo durante el examen final**.
